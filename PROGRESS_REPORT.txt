1. WHAT THE PROJECT IS
-------------------------------------------------------------------------------
A clean-room Python reimplementation of the GPL-licensed Java artillery game
"Graphwar" (NORMAL_FUNC mode). A shot is the graph of a function y = f(x); the
projectile traces that curve and explodes on the first thing it touches. The
reference Java source (`ref/graphwar/`, cited by file:line, never copied) is
the spec; the Python code is MIT-licensed and lives in `graphwar_sim/`,
`agents/`, and `eval/`.

The plan (IMPLEMENTATION_PLAN.md) sequences M0-M4 (ground truth, simulator,
deterministic solver, agents, eval harness — all DONE and merged) plus an M5
extension (5.1-5.5: corridor proof layer, certified corridor fit, agent
budgets, personas). M5.1 is merged; M5.2 (CCF) is implemented in the working
tree awaiting its measured report + commit.

4. WHAT IS IN THE WORKING TREE RIGHT NOW (M5.2, uncommitted)
-------------------------------------------------------------------------------
New files
  graphwar_sim/ccf.py        (~1260 lines)  CERTIFIED CORRIDOR FIT — the
                             M5.2 milestone. A certified fit of y = f(u)
                             through the cell-wise corridor: the emitted
                             expression is PROVEN (not merely observed) to
                             keep the trajectory inside the free geometry,
                             or the outcome says exactly why not.
    - Basis (5.2.md §3): Gaussians phi_j = exp(-(u-c_j)^2/(2 sigma^2)) on a
      uniform centre grid + FREE affine terms (f'' = 0): the affine absorbs
      the endpoint constraints and is excluded from the L1 budget.
    - Curvature bound (§4): max|f''| <= s / sigma^2 where s >= ||w||_1 — a
      NORM of the decision variables, so the interpolation margin
      M du^2/8 is LINEAR in the weights and lives INSIDE the LP. No
      fit-then-check loop.
    - LP (§6) via scipy.optimize.linprog (HiGHS): minimize s + mu(|a|+|b|)
      + lambda*slack s.t. fitted samples inside corridor envelopes exactly
      (rows written in sparse COO), endpoint equalities f(0)=0,
      f(u_T)=dy_T, and the margin charged linearly to s.
    - MILP cardinality fallback (§7, scipy.optimize.milp): |w_j| <= B z_j,
      sum z_j <= J_max, plus prune-to-fit + RE-VERIFY when MILP times out.
    - Branch selection (§8): K best corridor chains ordered by a
      slope-change proxy (the M5.1 parent-DAG backtraces ARE the
      slope-cap-feasible paths); "over"/"under" kind recorded.
    - Sigma ladder (§9) coarse->fine (4.0 ... 0.25), first feasible wins;
      LP pruning followed by MANDATORY re-verification (pruning moves the
      curve; on any violation the unpruned solution is restored).
    - Emission (§2): balanced-tree nesting (parse depth log2 J, pinned by
      test), plain decimals only (the parser's - to +- rewrite corrupts
      scientific notation), J_max DERIVED from the real formatter via
      emission_budget() against config.MAX_EXPR_CHARS (=2000, a harness
      cap — the reference imposes none; OPEN_QUESTIONS (e)).
    - Launch-nudge allowance (GROUND_TRUTH §2.4): the game nudges the start
      along the converged tangent; CCF charges an analytic allowance
      ((3/2) r_eff^2 / sigma^2) * s inside the LP ("allowance" mode), or
      falls back to "tight" mode: reconstruct the FIRED curve through the
      real launch-angle code and re-check every corridor sample.
    - Outcomes (§10): CERTIFIED / UNCERTIFIED / EMIT_OVERFLOW /
      BASIS_INFEASIBLE / UNREACHABLE, each escalation carrying the bound,
      the u_k, the sigma and the branch. Per-invocation instrumentation
      (§12) packaged in CCFCertificate.
  graphwar_sim/emission.py   (~60 lines)   emission moved OUT of solver.py
                             into a shared module: format_literal
                             (plain decimals), gauss_term (sign folding),
                             balanced_sum (log2-depth nesting). Single

  tests/test_emission.py     (~105 lines)  emission unit tests: plain-decimal
