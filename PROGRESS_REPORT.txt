1. WHAT THE PROJECT IS
-------------------------------------------------------------------------------
A clean-room Python reimplementation of the GPL-licensed Java artillery game
"Graphwar" (NORMAL_FUNC mode). A shot is the graph of a function y = f(x); the
projectile traces that curve and explodes on the first thing it touches. The
reference Java source (`ref/graphwar/`, cited by file:line, never copied) is the
spec; the Python code is MIT-licensed and lives in `graphwar_sim/`, `agents/`,
and `eval/`.

The plan (IMPLEMENTATION_PLAN.md) sequences five phases M0-M4. M0-M2 were
complete before this session; M3 (agents, minimal slice) and M4 (eval harness,
minimal slice) were delivered in this session.

8. KNOWN LIMITS / RECORDED DIVERGENCES (docs/OPEN_QUESTIONS.md)
-------------------------------------------------------------------------------
  - The per-SHOT rung distribution in the leaderboard (dud=297) is dominated
    by repeated duds on unreachable maps and cap-length matches; it is NOT a
    regression vs the M2 battery's per-SEED 33/40 first-shot hit rate.
  - 7 of 40 seeded maps have no monotone-x path (terrain occlusion): a safe dud
    is the correct degradation there (seed 31 is a documented knife-edge).
  - Random-agent friendly-fire observed (2 shots in the leaderboard) — expected
    from an unaimed baseline; the solver has 0 friendly fire.
  - Fixed-grid Gaussian basis sits low in the ladder (plan-order divergence,
    recorded M2).
