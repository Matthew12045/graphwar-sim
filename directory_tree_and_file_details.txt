graphwar_sim/config.py  (141 lines)
    All numeric constants, each cited to the Java source (Constants.java,
    FunctionToken.java). Plane geometry (770x450, PLANE_GAME_LENGTH=50),
    terrain circle distributions (mean radius 40 sd 25; mean count 15 sd 7),
    soldier radius 7 / selection 15 / min Chebyshev spacing 20, explosion
    radius 12, integration (FUNC_MAX_STEPS=20000, max step dist^2=0.001,
    min x step 1e-5, STEP_SIZE=0.01), angle iteration (pi/360, 100 loops),
    teams/modes (TEAM1/2, NORMAL_FUNC/FST_ODE/SND_ODE), match shape (max 10
    players, 4 soldiers each, 2 initial, 60s turns), and the 18 token-type
    codes with precedence. Helpers: is_operation(), get_num_param().

graphwar_sim/parser.py  (433 lines)
    Faithful port of Graphwar.PolishNotationFunction — the expression
    tokenizer + prefix (Polish) reordering + recursive-descent evaluator.
    Security surface: no eval/exec/sympify; LLM strings never reach Python
    code-evaluation. Replicates Java Math IEEE-754 edge cases (_java_div,
    _java_sqrt, _java_log, _java_log10, _java_pow, _java_sin/cos/tan) so
    NaN/Inf propagate like the JVM. MalformedFunction is a message-free
    exception, matching the reference. Handles implicit multiplication,
    -→+- rewrite, e/pi constants, and the full operator whitelist.

graphwar_sim/physics.py  (275 lines)
    The heart of the simulator: port of Function.processFunctionRange
    (Function.java:173-309). Integrates y=f(x) with adaptive step-halving,
    applies the TEAM2 mirror, the muzzle offset, and the auto vertical offset
    (offSet = -f(x0)+y0). Hit test: strict dist^2 < SOLDIER_RADIUS^2 in
    plane coords; trajectory continues past hits (multi-kill); only the
    shooter's current-turn soldier is skipped. Dataclasses: Soldier, Obstacle
    (collide_point grid), ShotResult (points, hits, last_x/last_y, num_steps).
    Reproduces the source quirk that the inverse transform uses PLANE_LENGTH
    for both axes.

graphwar_sim/state.py  (362 lines)
    Match layer: Team (player + soldiers + current-turn soldier cycling per
    Player.nextTurn), GameState (turn advancement per GameData.nextTurnMessage,
    win rule per checkGameFinished — game ends when a side has no living
    soldier), Game (create(seed) deterministic map, fire() applies kills per
    GameData.processFunction, play_turn(), winner()). make_circle_obstacle
    builds a crisp-circle terrain grid (OOB collides). generate_map: seeded
    terrain circles (reference distributions) + soldier placement (TUNABLE
    stand-in: side thirds, off-terrain, 5-point clearance, Chebyshev spacing).

graphwar_sim/solver.py  (513 lines)
    M2 deterministic no-LLM solver. solve(game) -> SolverResult with a legal,
    self-verified y=f(x) expression (verified through the real integrator;
    never hits a teammate). Works in a shooter-facing world frame (TEAM2 mirror
    folded in). Primary basis: sum of Gaussians, linear in weights, least
    squares; piecewise-linear integration gap certified via |f''| bound
    M = 2b * sum|w_j|. Degradation ladder (rung recorded):
    per_target_gaussian → parabola/line → fixed_grid_gaussian → arc (terrain-
    aware quadratic sweep) → dud. Emission via _num (plain decimals only —
    scientific notation would be corrupted by the parser's -→+- rewrite).
    run_battery() runs the seeded-map battery and reports hit rate + rung mix.

graphwar_sim/render.py  (219 lines)
    Headless matplotlib (Agg backend) rendering in plane/pixel space:
    obstacle_to_image (rasterize terrain to a bool grid — the same grid
    GoldenShot dumps for parity), render_state (terrain + team-colored
    soldiers + optional shot trajectory), render_match (final board + all
    shot trajectories, used by the eval harness for per-match plots).

agents/base.py  (169 lines)

agents/observation.py  (128 lines)
    observe(game) -> Observation: builds the centered-world-frame board for the
    current turn (mirror for TEAM2), sorts enemies nearest-first, samples
    terrain on a coarse 15px grid into world-space blocked cells, and renders
    the 70x32 ASCII board (x in [-25,25], y in [-15,15]).

agents/simulate_tool.py  (70 lines)
    The pure physics oracle: simulate(game, expr) -> SimResult (parseable,
    hit_enemy, hit_teammate, num_hits, num_steps, error). Fires the candidate
    through the real parser + process_function_range WITHOUT applying kills,
    so an agent can probe before committing. No eval/exec/sympify.

agents/baselines.py  (117 lines)
    StraightShotAgent: aims a straight line (m*x) at the nearest enemy in the
    world frame (usually dies at terrain — that's the point of a baseline).
    RandomAgent: seeded sampler over a small closed grammar (line / quadratic /
    sine / Gaussian), validating each emission through the real parser with a
    10-retry budget before falling back to the safe dud "0*x".

agents/solver_agent.py  (37 lines)
    SolverAgent: stateless wrapper around the M2 solver — each turn re-runs
    solve(game) and emits result.expression verbatim; records rung_history
    (degradation rung per shot) as a Phase-4 informational metric.

agents/emission.py  (19 lines)
    Re-exports graphwar_sim.solver._num as format_literal: the canonical
    plain-decimal number formatter shared by all agents (exponents would be
    corrupted by the parser's -→+- rewrite).
